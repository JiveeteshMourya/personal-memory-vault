# Phase 01 — UI Shell & Design System

> **Status:** ✅ Done · **Depends on:** 00 · **Unlocks:** 03 and every phase with UI

## Goal

Set the visual language and app chrome:

- design tokens with light/dark theme
- component primitives
- a landing page that explains the vault
- the dashboard shell, with navigation to every future section as placeholder pages

The agent has full design freedom. The user will ask for edits.

## Coupling boundary

- **Owns:** `src/app/globals.css` tokens, `src/components/ui/*`, `src/components/layout/*`, the `/` landing page, and the `(dashboard)` route group's layout and placeholder pages.
- **Must not:** fetch data or add auth. The shell stays public until Phase 03 protects it. Placeholders show static empty states.

## Contract provided

- **Primitives:** `src/components/ui/*`, generated by the shadcn CLI on Base UI (see the handoff notes for the list and conventions).
- **Layout pieces** in `src/components/layout/*`:
  - `AppShell` wraps every dashboard page (already applied by `src/app/(dashboard)/layout.tsx`).
  - `PageHeader({ title, description?, actions? })`: every dashboard page starts with one. `actions` is where page-level buttons go.
  - `EmptyState({ icon, title, description, action? })`: built on the shadcn `Empty` primitive.
- **Dashboard route map** (above). Feature phases replace the placeholder content of their page. They do not restructure the shell.
- **Nav config:** the single `navItems` array in `src/components/layout/nav-items.ts` (`{ href, label, icon }`). Later phases add entries there, e.g. "Requests" in Phase 14. Active highlighting is automatic (longest matching href).
- **Theme:** `src/lib/theme.ts` (`Theme`, `setTheme`, `applyTheme`, `readStoredTheme`), `ThemeToggle` from `src/components/theme-toggle.tsx`. Dark mode is the `.dark` class on `<html>`.
- **Toasts:** `import { toast } from "@/components/ui/toast"` and call `toast.add({ title, description?, type? })` from client code. `<Toaster />` is mounted once in the root layout.
- **Shared brand pieces:** `Logo` / `LogoMark` from `src/components/logo.tsx`.
- **Tokens:** semantic Tailwind colors (`bg-primary`, `text-muted-foreground`, …) plus the vault-specific `key` (brass, for key/consent moments) and `withheld` (redaction fill). Never raw palette colors.

**Gotchas for later phases:**

- **Base UI, not Radix:**
  - Custom triggers use `render={<Button … />}`, not `asChild`.
  - A `Button` rendering a link needs `render={<Link href="…" />} nativeButton={false}`.
  - `Select` takes an `items` prop.
  - Read `.claude/skills/shadcn/rules/base-vs-radix.md` before using a primitive.
- **shadcn skill rules:**
  - Forms use `FieldGroup` + `Field`.
  - Menu items go inside their `Group`.
  - Dialog/Sheet always get a Title.
  - Icons in buttons use `data-icon`, with no size classes.
  - Use `gap-*`, not `space-*`.
  - Add primitives with `bunx --bun shadcn@latest add <name>`, then run `bun run format`.
- **Generated primitives are locally edited:** `transition-all` → `transition` in button, badge and tabs. When updating a primitive with `shadcn add --diff`, keep that change.
- **`usePathname` and Suspense:** the sidebar's `SidebarNav` sits in `<Suspense fallback={<NavList />}>`. Under Cache Components, `usePathname` suspends when a page below has an unknown dynamic param (e.g. `memories/[id]`). The boundary keeps the shell static; don't remove it.
- **Phase 03's `proxy.ts` must redirect, never rewrite.** `usePathname` on a prerendered page behind a proxy rewrite causes hydration mismatches (`use-pathname.md`).
- **Theme:**
  - Never read the theme on the server (no cookie). The page always prerenders light, and the script corrects it before paint.
  - UI that depends on the theme must use `dark:` variants or tokens, not JS state, or it will mismatch on hydration.
- **Client vs server components:** shadcn components that need the client already carry `"use client"`. Pages and layout pieces can compose them as Server Components (e.g. `UserMenu`, `VaultLens` and `EmptyState` are server-rendered).
- **The user menu is a placeholder.** Phase 03 replaces the contents of `src/components/layout/user-menu.tsx`.
