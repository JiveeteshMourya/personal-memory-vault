PROJECT KA SCENE
-----------------
Basically ek "memory locker" hai AI apps ke liye. Har AI app (fitness coach,
mood journal, meal planner) user ke baare mein thoda-thoda jaanta hai, par
sab alag-alag. Vault beech mein baithta hai: apps yahan likhte hain, yahan se
poochte hain, aur har app ko sirf utna milta hai jitna owner ne allow kiya.
Jawab max 100 characters ka. Gossip ka koi scope nahi.

Example: Jane fitness app ko bolti hai "Did a 5k this morning, knee felt a
bit sore after." Vault isse do memories banata hai: run (activity) aur knee
(health). Fitness app ke paas health likhne ki permission nahi? Toh run save,
knee withheld. App ko bas itna pata chalta hai ki "ek health wali cheez
ruki". Kya ruki, woh nahi.

Tech Stack : Next.js 16, React 19, TypeScript, Bun, PostgreSQL 17 (Drizzle),
             Qdrant, OpenAI (gpt-6-luna + text-embedding-3-small),
             Better Auth, zod, Tailwind + shadcn/ui
Architecture: models -> repository -> services -> controllers + middlewares
             (fancy naam: layered architecture; asli matlab: har cheez ki
             apni file, aur har file ka apna ego)

    team mein kaam baanta. Main character energy, but with documentation.
  - Saare key engineering decisions:
      * AI kabhi authorise nahi karega. AI padhta, samajhta, likhta hai;
        "kaun kya dekhega" plain code decide karta hai. Non-negotiable.
      * Platform-agnostic API: "workout endpoint" jaisa koi app-specific
        raasta nahi. Free text bhejo, normal sawaal poocho. Koi bhi GenAI
        app jud sakta hai, vault badle bina.
      * Vectors hosted service se local Qdrant (Docker) pe shift. Data owner
        ki machine pe hi rahega. Period.
      * 16 categories + 4 harm-based sensitivity tiers ka taxonomy.
      * 15 Nov 2026: plan phase 17 tak tha, demo 17 Nov ko. Bacha kaam 4
        phases (06-09) mein samet diya. Calendar ne challenge kiya, lead ne
        accept kiya.
  - GenAI pipeline (src/server/lib/ai.ts):
      * extractMemories() — free text ko chhoti English memories mein todna,
        aur "this morning" ko asli date banana. Structured Outputs, toh AI
        form bharta hai, essay nahi. "Vibes" naam ki category exist nahi
        karti, sorry.
      * Passwords, API keys, card numbers redact. Kabhi save nahi hote.
      * App ka text AI ko data ki tarah jaata hai, hukum ki tarah nahi.
        "Ignore previous instructions" likha? Cute. Ignored.
      * Har request `store: false`. OpenAI padhe, yaad na rakhe.
      * rewriteQuery() — "aur dinner?" jaisa adhoora sawaal poora banta hai.
  - Semantic index + similarity search (RAG ka "R"):
      * embed() — har memory 1536 numbers ki list. Same matlab = paas paas.
        "Neend" dhoondo toh "raat bhar jaagi" mil jaata hai, bina ek common
        word ke.
      * indexMemories() / searchMemoryIds() — Qdrant mein sirf labels,
        content kabhi nahi. Permission filter search ke ANDAR lagta hai,
        toh jo allowed nahi woh result mein aata hi nahi.
      * Qdrant mein khaali filter = "sab match". Toh scope khaali hai toh
        search hi cancel. Default deny, no exceptions.
      * 0.2 similarity cutoff, naap ke rakha: unrelated sawaal max 0.14,
        relevant 0.26-0.53. Vibes se nahi, data se.
  - Context projection (project ka main event, requestContext()):
      * App sawaal poochta hai, vault max 100 characters ka jawab deta hai,
        app ke purpose ke hisaab se. Tweet se chhota, kaam ka poora.
      * Flow: scope narrow -> embed -> filtered search -> har row re-check
        -> rerank (similarity + recency + importance + confidence, top
        8/20/40) -> projectContext() -> capChars() poore sentence ya shabd
        pe kaatta hai.
      * withheldCategories mein sirf woh jo app ne khud maangi. Demo mein
        fitness app ne finance bhi maanga. Mila "withheld". Salary ka "S"
        bhi nahi. Too bad bestie.
      * Access log mein exactly wahi memories jo jawab mein gayi.
  - Policy engine (access-policy.service.ts + grant.service.ts):
      * evaluateAccess(), canRead(), canWrite(), getAccessScope(). Pure
        functions: na DB, na AI. Same input, same output. Boring? Haan.
        Security mein boring = W.
      * Read ke 4 checks: category + tier cap, allowed source, shared ya
        apni likhi, expired nahi. Ek bhi fail toh "nahi".
  - Write pipeline (ingestMemories(), finalize()): AI tier propose karta hai,
    vault decide karta hai. Sensitivity floor sirf upar le jaata hai, app ka
    andaaza max 0.6 confidence. Delulu is not the solulu here.
  - Qdrant fail hua toh DB insert bhi undo. "Stored" ka matlab hamesha
    "searchable". Adhoora kaam is vault mein allowed nahi.
  - runPlaygroundAction() (Playground ka engine) aur `bun run reindex`.
  - Phase index, har phase ka doc, Decisions Log, Pivot Log, public API doc,
    classification model doc. Yaani project ka poora manual.
